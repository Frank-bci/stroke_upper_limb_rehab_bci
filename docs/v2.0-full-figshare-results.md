# v2.0 Full Figshare Riemannian Results

本轮实验使用 `configs/v2/figshare_stroke_full_riemannian.yaml`，覆盖本机已有的 50 个 Figshare stroke EDF 文件。

## Offline

- 有效 epoch: 3749 / 4000
- 训练 epoch: 2785
- 测试 epoch: 964
- 训练 window: 13925
- 测试 window: 4820
- split: subject hold-out
- balanced accuracy: 0.6430
- AUC: 0.6909
- F1: 0.6397

相比 v1.0 FBCSP + LDA 全量 Figshare 结果，v2.0 Riemannian baseline 的离线指标有提升。

## Threshold

交叉验证阈值校准选择 `0.55`：

- CV trigger rate: 0.1976
- CV false trigger rate: 0.0816

但 held-out test 在 `0.55` 上误触发率为 0.1129，略高于 10% 目标。因此 held-out 阈值扫描建议使用 `0.60` 作为当前操作点：

- trigger rate: 0.1368
- false trigger rate: 0.0403
- mean trigger delay: 1.0508s

## Subject Findings

`0.60` 阈值下仍有明显 subject 差异：

- 表现较好: `sub-11`, `sub-47`
- 误触发风险高: `sub-21`, `sub-43`
- 几乎不触发或弱可解码: `sub-02`, `sub-23`, `sub-31`

这说明 v2.0 的下一步重点应从单一全局阈值转向 subject/session 级个性化阈值，或者引入拒识机制，避免对不可解码 subject 强行触发。

## Personalized Thresholds

`scripts/tune_subject_thresholds.py` 对每个 held-out subject 分别扫描阈值，并在误触发率不超过 10% 的候选中选择触发率最高的阈值。

个体化阈值汇总结果：

- trigger rate: 0.2521
- false trigger rate: 0.0363
- mean trigger delay: 1.0614s
- ready_for_trigger: 12 subjects
- monitor_only_low_trigger: 1 subject (`sub-35`)

与全局 `0.60` 阈值相比，个体化阈值把触发率从 0.1368 提升到 0.2521，同时误触发率从 0.0403 降到 0.0363。这个结果支持 v2.1 进入 subject/session 级阈值策略。

## Repeated Subject Splits

`scripts/evaluate_repeated_splits.py` 使用 3 个随机种子重新做 subject hold-out split，并在每个 split 上重新训练 Riemannian 模型。

3 次 split 的汇总结果：

- offline balanced accuracy: 0.6399 ± 0.0029
- offline AUC: 0.6927 ± 0.0046
- global trigger rate: 0.1273 ± 0.0563
- global false trigger rate: 0.0366 ± 0.0221
- personalized trigger rate: 0.2538 ± 0.0181
- personalized false trigger rate: 0.0371 ± 0.0035
- ready-only personalized trigger rate: 0.2451 ± 0.0281
- ready-only personalized false trigger rate: 0.0338 ± 0.0066

结论：离线指标和个体化阈值收益在不同 subject split 上比较稳定。全局阈值的触发率波动较大，进一步支持 v2.1 采用 subject/session 级阈值，而不是单一全局阈值。

## Error Analysis

`scripts/analyze_subject_errors.py` 对高风险 subject 的窗口级概率、质量分数和误触发 trial 做诊断。本轮重点检查 `sub-21` 和 `sub-43`。

在个体化阈值 `0.65` 下：

- `sub-21`: trigger rate 0.0526, false trigger rate 0.0789
- `sub-43`: trigger rate 0.2813, false trigger rate 0.0263

两个 subject 的误触发在个体化阈值后已经可控，但 rest 概率分布整体偏高：

- `sub-21` rest probability mean 0.5575, p95 0.6854
- `sub-43` rest probability mean 0.5956, p95 0.6870

误触发窗口的质量分数多数在 80 左右，不像是简单低质量信号造成。更可能的原因是 rest 与 motor-intention 分布在这些 subject 上重叠，或共享事件时间/epoch 截取策略对个别 EDF 不完全匹配。

## Event Audit

`scripts/audit_figshare_events.py` 检查共享 `task-motor-imagery_events.tsv` 和 50 个 EDF 的匹配情况。

审计结果：

- 50 个 EDF 都没有内嵌 annotations，当前 loader 必须依赖共享 events TSV。
- 共享 events TSV 有 120 行：40 个 instruction、40 个 motor imagery、40 个 break。
- 当前 loader 忽略 `value=1` instruction，使用 `value=2` 作为 motor_intention，`value=3` 作为 rest。
- 每个 EDF 都可得到 40 个 motor epoch + 40 个 rest epoch。
- 所有 motor/rest event 按当前 loader 的 sample-index 逻辑都在 EDF 范围内。
- 最后一条 break event 标称结束时间是 320.001s，比 EDF 320.0s 多约 1ms；但 sample-index 转换后仍然正好在界内。

结论：当前 Figshare 加载逻辑在事件数量和边界上是自洽的。`sub-21`、`sub-43` 的 rest 概率整体上移，暂时不像是事件数量或 EDF 覆盖问题，更像是 subject/session 分布漂移，下一步应尝试 per-subject baseline correction 或 session normalization。

## Epoch Standardization

`configs/v2/figshare_stroke_full_riemannian_epoch_standardized.yaml` 在 Riemannian pipeline 前增加了 epoch-level channel z-score，用于验证简单幅值/基线漂移校正是否有效。

结果：

- offline balanced accuracy: 0.6129
- offline AUC: 0.6562
- offline F1: 0.6068
- global threshold 0.55: trigger rate 0.2735, false trigger rate 0.0927
- personalized trigger rate: 0.2222
- personalized false trigger rate: 0.0302
- ready_for_trigger: 9 subjects
- not_ready_low_auc: 3 subjects
- monitor_only_low_trigger: 1 subject

对 `sub-21` 和 `sub-43`，epoch standardization 降低了 rest probability 的整体水平：

- `sub-21` rest mean 从 0.5575 降到 0.5140，false trigger rate 从 0.0789 降到 0.0263
- `sub-43` rest mean 从 0.5956 降到 0.5226，false trigger rate 保持 0.0263

但整体离线指标和个体化触发率低于原始 Riemannian 模型，且更多 subject 被判为 low AUC。因此 epoch-level z-score 只能作为诊断结果，不建议作为 v2 默认主路线。下一步应尝试训练集统计驱动的 channel/session normalization，而不是每个 epoch 独立标准化。

## Train-Channel Standardization

`configs/v2/figshare_stroke_full_riemannian_train_channel_standardized.yaml` 使用训练 split 统计量对每个通道做标准化。与 epoch z-score 不同，它只在训练数据上 `fit` 均值和标准差，测试和在线窗口使用同一套训练统计，因此更接近真实部署。

结果：

- offline balanced accuracy: 0.6480
- offline AUC: 0.7028
- offline F1: 0.6344
- global threshold 0.55: trigger rate 0.3355, false trigger rate 0.0968
- personalized trigger rate: 0.3162
- personalized false trigger rate: 0.0363
- ready_for_trigger: 13 subjects

高风险 subject：

- `sub-21`: threshold 0.65, trigger rate 0.0526, false trigger rate 0.0263
- `sub-43`: threshold 0.65, trigger rate 0.4688, false trigger rate 0.0789

相比原始 Riemannian 主线，train-channel standardization 同时提高了离线 AUC、全局阈值触发率、个体化触发率，并让 13 个 held-out subjects 全部进入 ready 状态。这个版本应作为新的 v2 主候选，但仍需要 repeated subject split 验证。

## Per-Subject/Session Channel Standardization

注意：这个版本是诊断性实验。测试 subject 的标准化使用了该 subject 当前 session 的整体无标签统计量，部署时应改成校准窗口或在线滑动统计。

单次 subject split：

- offline balanced accuracy: 0.5844
- offline AUC: 0.6141
- offline F1: 0.5493
- global threshold 0.60: trigger rate 0.0876, false trigger rate 0.0504
- personalized trigger rate: 0.1774
- personalized false trigger rate: 0.0202

结论：per-subject/session channel standardization 虽然进一步压低了误触发，但同时显著降低了离线 AUC 和触发率，说明这种强标准化可能抹掉了对 motor intention 有用的幅值/协方差差异。当前不建议作为 v2 主线。下一步应尝试更温和的 covariance alignment，或只基于短校准窗口做在线自适应。

## Covariance Alignment

`configs/v2/figshare_stroke_full_riemannian_covariance_aligned.yaml` 在当前推荐主线基础上，在 `Covariances` 后、`TangentSpace` 前加入 Euclidean covariance alignment。该方法用训练 split 的协方差均值拟合 whitening 矩阵，再对训练和测试协方差做同一映射，比整段 subject/session channel z-score 更温和，也更贴近 Riemannian pipeline。

单次 subject split：

- offline balanced accuracy: 0.6472
- offline AUC: 0.7019
- offline F1: 0.6342
- global threshold 0.60: trigger rate 0.1688, false trigger rate 0.0444
- personalized trigger rate: 0.3141
- personalized false trigger rate: 0.0363
- ready_for_trigger: 12 subjects
- monitor_only_low_trigger: 1 subject

与当前推荐主线相比，covariance alignment 的 AUC 几乎持平但略低，个体化触发率也略低：

- 推荐主线 AUC: 0.7028，personalized trigger: 0.3162，false trigger: 0.0363
- covariance alignment AUC: 0.7019，personalized trigger: 0.3141，false trigger: 0.0363

结论：Euclidean covariance alignment 明显优于强 per-subject/session channel standardization，但没有超过当前 train-channel standardized Riemannian 主线。当前可保留为候选对照，不建议替换主配置。下一步更值得做的是校准窗口驱动的 subject adaptation，而不是用训练集全局协方差均值做统一对齐。

## Calibration-Window Threshold Adaptation

参考 WCDA 论文中“source subjects → target subject”的迁移学习思路，`scripts/evaluate_calibration_window_adaptation.py` 将 held-out subject 的少量早期 trial 作为 target-domain calibration window，只用这部分数据选择该 subject 的触发阈值，再在该 subject 剩余 trial 上评估。

这比 `tune_subject_thresholds.py` 更接近真实部署：后者使用整个 held-out subject 来调阈值，偏乐观；新脚本只使用前置校准窗口。

当前推荐主线配置 `configs/v2/figshare_stroke_full_riemannian_train_channel_standardized.yaml` 上的结果：

5 trials/class calibration，校准约束 false trigger ≤ 0.10：

- evaluation trigger rate: 0.3499
- evaluation false trigger rate: 0.0626
- mean trigger delay: 1.0709s
- ready_for_trigger: 6 subjects
- monitor_only_low_trigger: 3 subjects
- not_ready_high_false_trigger: 3 subjects
- not_ready_low_auc: 1 subject

10 trials/class calibration，校准约束 false trigger ≤ 0.10：

- evaluation trigger rate: 0.3905
- evaluation false trigger rate: 0.1120
- mean trigger delay: 1.0568s
- ready_for_trigger: 5 subjects
- not_ready_high_false_trigger: 4 subjects
- monitor_only_low_trigger: 2 subjects
- not_ready_low_auc: 2 subjects

5 trials/class calibration，校准约束 false trigger ≤ 0.05：

- evaluation trigger rate: 0.3499
- evaluation false trigger rate: 0.0626
- mean trigger delay: 1.0709s
- ready_for_trigger: 5 subjects
- monitor_only_low_trigger: 3 subjects
- not_ready_high_false_trigger: 4 subjects
- not_ready_low_auc: 1 subject

结论：校准窗口阈值适配能在剩余 evaluation trials 上取得比全量个体化阈值更高的触发率，但 subject 稳定性不足；10 trials/class 甚至让评估误触发超过 10%。这说明当前策略有潜力，但还不能直接作为主线。下一步需要更细阈值网格和更保守的 subject-level 选择规则，例如在校准集上对误触发加入 safety margin，或要求阈值在相邻候选上也满足约束。

### Calibration-Window Adaptation v2

`scripts/evaluate_calibration_window_adaptation.py` 增加了两个保守选择机制：

- `--false-trigger-margin`: 在校准窗口中使用更严格的误触发约束，例如把 0.10 约束实际收紧到 0.075。
- `--threshold-safety-steps`: 在选中阈值后向更高阈值上推若干档，降低上线误触发风险。

使用更细阈值网格 `[0.50, 0.525, ..., 0.75]` 后，5 trials/class calibration 的结果：

Fine grid，无 safety：

- evaluation trigger rate: 0.3275
- evaluation false trigger rate: 0.0580
- mean trigger delay: 1.0701s
- ready_for_trigger: 5 subjects
- monitor_only_low_trigger: 4 subjects
- not_ready_high_false_trigger: 3 subjects
- not_ready_low_auc: 1 subject

Fine grid，threshold safety step = 1：

- evaluation trigger rate: 0.2283
- evaluation false trigger rate: 0.0371
- mean trigger delay: 1.0734s
- ready_for_trigger: 5 subjects
- monitor_only_low_trigger: 5 subjects
- not_ready_high_false_trigger: 2 subjects
- not_ready_low_auc: 1 subject

Fine grid，false-trigger margin = 0.025 且 threshold safety step = 1：

- evaluation trigger rate: 0.2283
- evaluation false trigger rate: 0.0371
- mean trigger delay: 1.0734s
- ready_for_trigger: 5 subjects
- monitor_only_low_trigger: 5 subjects
- not_ready_high_false_trigger: 2 subjects
- not_ready_low_auc: 1 subject

结论：细阈值网格能把 5 trials/class 校准的误触发从 0.0626 降到 0.0580，同时保留 0.3275 的较高触发率，是当前校准窗口策略中较好的折中点。上推一档能进一步压低误触发到 0.0371，但触发率下降到 0.2283，过于保守。当前不建议把 calibration-window adaptation 直接替换主线，但可以作为 v2.1 触发策略候选继续做 repeated split 与 subject-level reject 规则。

## Next

- 将 train-channel standardized Riemannian 设为 v2 推荐主配置。
- 不采用简单 EEG-only 排除策略作为主线。
- supervised top-24 的 EOG/空通道风险已确认；no-EOG top-24 性能下降。
- 强 per-subject/session channel standardization 已验证为负向对照。
- Euclidean covariance alignment 接近主线，但没有清晰收益。
- calibration-window adaptation v2 中，细阈值网格无 safety 是当前较好的触发/误触发折中；上推一档更安全但触发率过低。
- 下一步优先做 calibration-window adaptation 的 repeated split 验证和 subject-level reject/monitor-only 规则。
