# v2.0 Clinical-Pre Baseline Plan

v1.0 已经完成了合成数据上的 MVP 验证。v2.0 的目标不是马上追求很高的准确率，而是建立一个能在真实 EEG 数据上持续迭代的实验框架。

## 目标

- 数据主线切换到 PhysioNet 和 Figshare stroke 真实数据。
- 保留 FBCSP + LDA 作为 v1.0 对照组。
- 新增 Riemannian tangent-space baseline，优先提高小样本 EEG 的鲁棒性。
- 引入概率校准和交叉验证阈值选择，避免只在训练集上调触发阈值。
- 输出离线指标、伪在线 session 报告和阈值校准报告，所有 v2 结果写入独立 `outputs/v2_*` 目录。

## 当前 v2.0 实验入口

快速真实数据实验：

```bash
python3 scripts/run_v2_experiment.py
```

单数据集运行：

```bash
python3 scripts/train_baseline.py --config configs/v2/figshare_stroke_riemannian.yaml
python3 scripts/simulate_online.py --config configs/v2/figshare_stroke_riemannian.yaml
python3 scripts/calibrate_trigger_threshold.py --config configs/v2/figshare_stroke_riemannian.yaml
```

全量 Figshare 实验：

```bash
python3 scripts/train_baseline.py --config configs/v2/figshare_stroke_full_riemannian.yaml
python3 scripts/simulate_online.py --config configs/v2/figshare_stroke_full_riemannian.yaml
python3 scripts/calibrate_trigger_threshold.py --config configs/v2/figshare_stroke_full_riemannian.yaml
```

## 通过标准

- 离线 balanced accuracy 高于或接近 v1 真实数据 baseline。
- AUC 稳定高于 0.60，说明概率排序有可用信号。
- 阈值校准后的 held-out false trigger rate 控制在 10% 以内。
- 触发率不能只靠降低阈值虚高，需要同时报告误触发率和平均触发延迟。

## 下一轮优化

- 增加 per-subject 报告，定位可解码和不可解码受试者。
- 对比 `riemannian_logreg`、`riemannian_lda`、`fbcsp_logreg`。
- 尝试 subject/session 级个性化阈值。
- 在全量数据上固定随机种子，重复多次 subject split，报告均值和置信区间。
