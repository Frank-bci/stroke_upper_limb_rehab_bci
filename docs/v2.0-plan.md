# v2.0 Clinical-Pre Baseline Plan

v1.0 已经完成了合成数据上的 MVP 验证。v2.0 的目标不是马上追求很高的准确率，而是建立一个能在真实 EEG 数据上持续迭代的实验框架。

## 目标

- 数据主线切换到 PhysioNet 和 Figshare stroke 真实数据。
- 保留 FBCSP + LDA 作为 v1.0 对照组。
- 新增 Riemannian tangent-space baseline，优先提高小样本 EEG 的鲁棒性。
- 引入概率校准和交叉验证阈值选择，避免只在训练集上调触发阈值。
- 输出离线指标、伪在线 session 报告和阈值校准报告，所有 v2 结果写入独立 `outputs/v2_*` 目录。

## 通过标准

- 离线 balanced accuracy 高于或接近 v1 真实数据 baseline。
- AUC 稳定高于 0.60，说明概率排序有可用信号。
- 阈值校准后的 held-out false trigger rate 控制在 10% 以内。
- 触发率不能只靠降低阈值虚高，需要同时报告误触发率和平均触发延迟。
- 当前推荐主配置为 `configs/v2/figshare_stroke_full_riemannian_train_channel_standardized.yaml`。

## 下一轮优化

- PhysioNet 左右手 MI 当前推荐 `riemannian_logreg`，但 `riemannian_lda` 表现非常接近。
- FBCSP 在 20-subject 左右手 MI 上接近随机，暂不作为 PhysioNet 主 baseline。
- PhysioNet `left-hand MI` vs `right-hand MI` 已建立为健康数据 sanity check；下一步扩展更多 subject/任务 runs。
- 补充健康公开数据对照时，不直接沿用 Figshare 的 rest-vs-MI 结论。
- Figshare 简单 EEG-only 排除策略已验证为负向对照，训练集内 top-k 通道选择也存在 EOG/空通道风险。
- Figshare supervised top-24 提升了个体化触发率，但 100% 选择 EOG/空通道；no-EOG top24 性能下降，不建议作为主线。
- per-subject/session channel standardization 已验证为诊断性负向对照：误触发降低，但 AUC 和触发率明显下降，不建议作为主线。
- Euclidean covariance alignment 接近当前推荐主线，但 AUC 和个体化触发率没有清晰超过主线，暂不替换推荐配置。
- 下一步优先做只使用校准窗口统计的在线自适应，避免整段 session 强标准化或全局协方差对齐抹掉个体差异。
